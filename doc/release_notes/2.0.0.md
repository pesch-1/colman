First public release of **colman**, a library and collection manager for
school libraries, built with Qt 6 and SQLite.

Colman was originally written to handle **class sets**: many copies of the
same workbook can be acquired, lent, returned or liquidated in a single step,
without registering every copy individually. It also works for private
collections of books, CDs, DVDs, board games and other items.

> Why 2.0.0? Colman has been developed and used since 2015; this is the
> first version published on GitHub.

## Highlights

- **Guided workflows** for lending, returning, acquiring and liquidating
  items, including group lending and group return
- **Items and persons** with collection-specific Code128 barcodes, printable
  ID cards and labels, and thermal-printer support
- **Flexible item types** with custom attributes and MARC21 field mapping;
  ISBN lookup from online sources
- **Undo/redo**, reports and print preview
- **Single-machine mode** with a local `.col` SQLite database, or
  **REST mode**: `colman_rest_server` shares one database with several
  `colman_rest_client` instances and the Flutter mobile client
  (REST API 2.6)
- **Authentication** in REST mode: local users (Argon2), JWT/OIDC
  (e.g. Authentik) or password-less barcode login for reserve-only persons;
  fine-grained, delegable permissions
- Server discovery on the local network via mDNS
- **Admin tools**: `colman_transfer` (CSV/JSON import and export) and
  `colman_gen_testdb`
- User interface in **English and German**

## Downloads

| File | Contents |
|---|---|
| `colman-2.0.0.tar.gz` | Source distribution |
| `colman-2.0.0-linux-x86_64.tar.gz` | Self-contained Linux binary (x86_64, Qt bundled) |

To build from source, you need Qt ≥ 6.4.2, CMake ≥ 3.21, libsqlite3 and
libargon2. See [INSTALL.md](https://github.com/pesch-1/colman/blob/v2.0.0/INSTALL.md)
for build instructions.  colman currently runs on Linux only; the
Flutter client runs on Android.
