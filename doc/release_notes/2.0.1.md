Maintenance release of **colman**, the library and collection manager.
The main change is that encrypted collections no longer depend on an
external Qt plugin.

## Changes

- **Built-in encryption:** colman now ships its own SQLite driver, built on
  [SQLite3MultipleCiphers](https://github.com/utelle/SQLite3MultipleCiphers)
  and linked into the program.  Encrypted collections therefore work
  everywhere, including the self-contained Linux bundle and the REST
  server, without installing the QSQLite3MultipleCiphers Qt plugin.
- Passwords of encrypted collections are passed to SQLite as UTF-8 and may
  now contain any character, including `;`.  New encrypted collections use
  the ChaCha20-Poly1305 cipher.
- **Android client:** the signed APK of the Flutter client is now offered
  as a download with every release, and the login screen shows the
  installed version.
- The Linux bundle contains `LICENSE`, `NOTICE` and the license texts of
  the bundled libraries (`usr/share/doc/colman/`).
- **Raspberry Pi:** the setup guide no longer needs the plugin build and
  recommends building serially (`-j1`), since parallel builds can run out
  of memory.
- The documentation now states the supported platforms: Linux (including
  the Raspberry Pi) and, for the mobile client, Android.

## Upgrading

- Collections encrypted with colman 2.0.0 open unchanged if their password
  consists of ASCII characters only.
- With 2.0.0, passwords containing non-ASCII characters (e.g. umlauts) were
  passed to SQLite incompletely.  Before upgrading, open such a collection
  with 2.0.0 and change its password to an ASCII-only one (or remove the
  encryption); after the upgrade you can set any password again.
- Building from source no longer needs `libsqlite3` or the Qt SQLite
  plugin; CMake downloads SQLite3MultipleCiphers while configuring, so
  internet access is required for the first build.

## Downloads

| File | Contents |
|---|---|
| `colman-2.0.1.tar.gz` | Source distribution |
| `colman-2.0.1-linux-x86_64.tar.gz` | Self-contained Linux binary (x86_64, Qt bundled) |
| `colman-2.0.1.apk` | Flutter client for Android |

The Linux binary needs glibc 2.38 or newer (e.g. Ubuntu 24.04, Debian 13,
Fedora 39); GLib and, for camera scanning, GStreamer with the "good"
plugins are taken from the system.  Unpack it and start `./AppRun`.

colman currently runs on Linux only; the Flutter client runs on Android.
To build from source, you need Qt ≥ 6.4.2, CMake ≥ 3.21 and libargon2.
See [INSTALL.md](https://github.com/pesch-1/colman/blob/v2.0.1/INSTALL.md)
for build instructions.
