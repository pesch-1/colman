Release of **colman**, the library and collection manager, with a first
**Windows preview**, separate server packages and an easier way to complete
existing items.

## New

- **Windows (preview):** colman, the REST client and the REST server now
  run on Windows 10 and 11 (64-bit).  Unpack the zip and start the program;
  no installation is needed.  Encrypted collections, camera scanning and
  direct printing on the supported label printers work as on Linux.  The
  Windows version is new and less tested than the Linux version — feedback
  is very welcome.  The programs are not signed yet, so Windows SmartScreen
  warns on the first start ("More info" → "Run anyway").
- **Fill in from the internet:** the item edit page has a new button that
  searches the internet for the item (by ISBN or EAN, otherwise by title;
  board games on BoardGameGeek) and fills in only empty fields and a
  missing cover image.  Everything already filled in is kept.  A cover
  counts as missing when none is set or its image file is not available.
- **Label printers without a print queue:** the supported thermal printers
  (Vevor Y486, Munbyn RW403B) are now offered as "… (USB)" when they are
  connected directly via USB, even if they are not set up in the print
  system.
- **Separate server packages:** the REST server comes in its own, much
  smaller package for Linux and Windows; the application package contains
  the desktop app and the REST client.

## Improvements and fixes

- Cover image file names no longer contain characters that are not allowed
  on Windows (such as `:` in "Title : Subtitle"); existing covers keep
  their names and are still found.
- The self-contained packages no longer include unused Qt database drivers.
- The documentation describes which fields can be changed when editing an
  item, the cover buttons on the edit page, and which thermal label
  printers are supported so far.

## Downloads

| File | Contents |
|---|---|
| `colman-2.0.2.tar.gz` | Source distribution |
| `colman-2.0.2-linux-x86_64.tar.gz` | Linux: desktop app and REST client |
| `colman-server-2.0.2-linux-x86_64.tar.gz` | Linux: REST server |
| `colman-2.0.2-windows-x64.zip` | Windows (preview): desktop app and REST client |
| `colman-server-2.0.2-windows-x64.zip` | Windows (preview): REST server |
| `colman-2.0.2.apk` | Flutter client for Android |

The Linux packages need glibc 2.38 or newer (e.g. Ubuntu 24.04, Debian 13,
Fedora 39); GLib and, for camera scanning, GStreamer with the "good"
plugins are taken from the system.  Unpack them and start `./AppRun`
(desktop app), `./usr/bin/colman_rest_client` or
`./usr/bin/colman_rest_server`.

To build from source, see
[INSTALL.md](https://github.com/pesch-1/colman/blob/v2.0.2/INSTALL.md)
(Linux and Windows).
